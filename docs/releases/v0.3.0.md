# PanBridge 0.3.0

本版本提供 Windows EXE 安装包，并接入系统的“启动应用”管理。

## 下载

- `PanBridge-0.3.0-Setup-x64.exe`：推荐，安装到当前用户目录，提供开始菜单入口、卸载和可选的 Windows 自启动；首次需要时可一并安装 WinFsp。
- `PanBridge-0.3.0-win-x64.zip`：便携版，完整解压后运行 `PanBridge.exe`。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

## 自启动

可在“偏好设置”中启用随 Windows 登录启动，也可在 Windows“设置 → 应用 → 启动”或任务管理器的“启动应用”中控制 PanBridge。

登录启动时仅在托盘运行，不弹出主窗口；勾选“启动客户端后自动连接云盘”后，会使用已有登录连接盘符。Windows 中禁用的启动项不会被程序启动或升级操作自动重新启用。

## 安装与更新

安装版默认位于 `%LOCALAPPDATA%\Programs\PanBridge`，登录数据和设置保存在该目录的 `data` 文件夹。更新前会请求正在运行的程序安全退出，上传未结束时不会强制终止进程。卸载保留本地数据及共享的 WinFsp 驱动。

需要 Windows 10/11 x64 和 WebView2 Runtime。WinFsp 驱动缺失时，安装程序可请求管理员权限静默安装。应用和安装包目前未做代码签名。

便携版用户更新时保留原 `data` 文件夹；改用安装版时，请先安全退出旧版，再复制原 `data` 到安装目录，或重新登录。不要分发个人 `data` 和缓存。
