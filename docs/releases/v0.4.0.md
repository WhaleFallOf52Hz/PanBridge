# PanBridge 0.4.0

本版本减小离线安装包和安装目录，同时保留现有登录、托盘、自启动、缓存和完整读写功能。

本机构建对比（不含个人数据及缓存，MiB）：

| 项目 | 0.3.1 | 0.4.0 |
| --- | ---: | ---: |
| 离线安装包 | 约 104 | 约 64.5 |
| 程序文件 | 约 349 | 约 199 |
| rclone 可执行文件 | 约 81.5 | 约 19.6 |

- 主程序与 Tbox 共用一套应用私有 .NET 8 运行时，无需另装 .NET。
- 精简 rclone 的云盘后端及命令，保留 Windows 挂载、WebDAV、缓存与上传控制。
- 保留简体中文和英文回退，移除不需要的语言资源、调试符号和 API 文档。
- 安装器按 SHA-256 复用未变化文件，清理校验匹配的旧版冗余组件，保留登录、设置、缓存和用户修改的文件。
- 新增分项体积报告、分发文件哈希清单和安装回归检查。

## 下载与更新

- `PanBridge-0.4.0-Setup-x64.exe`：完整离线安装包，可直接升级已安装版本。
- `PanBridge-0.4.0-win-x64.zip`：便携版，请解压到新目录，再迁移旧版 `data` 文件夹。
- `SHA256SUMS.txt`：安装包与便携包校验值。
- `package-info.json`：组件版本与未压缩体积报告。

升级前请等待上传完成。安装包和应用目前未签名。
