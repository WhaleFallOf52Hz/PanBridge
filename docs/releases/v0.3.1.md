# PanBridge 0.3.1

本版本修复资源管理器重命名文件夹时出现 `0x8007045D` 的问题。

## 修复内容

- WebDAV MOVE 会先识别源对象是文件还是文件夹。
- 文件夹重命名和移动改用交大云盘的目录移动接口；文件仍使用文件移动接口。
- 移动请求使用 JSON 序列化，支持包含中文、空格等字符的路径。
- 真实集成检查新增目录重命名、重命名后文件访问和清理验证。

## 下载

- `PanBridge-0.3.1-Setup-x64.exe`：Windows x64 安装包。
- `PanBridge-0.3.1-win-x64.zip`：便携版。
- `SHA256SUMS.txt`：下载文件校验值。

更新前请让旧版本从托盘安全退出。安装程序会保留登录资料、设置和缓存目录。
