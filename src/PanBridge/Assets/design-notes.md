# 交云桥图标

`PanBridge.svg` 是唯一设计源。PNG 和 ICO 均从 SVG 导出，生成式图片只作为最初的视觉参考，不参与最终渲染。

- 画布：1024 × 1024。
- 底板：`x=56, y=56, width=912, height=912, rx=184`，纯色 `#2868E8`。
- 桥形：单个闭合三次贝塞尔路径，填色 `#FAFCFF`。主轮廓的曲线接点使用共线切向量，直线与圆角连接处保持切线连续。
- 折面：`#76D8CF`，与桥形共享上侧曲线，裁切在同一桥形路径内，避免接缝溢出。
- 底板内部完全不透明，只有圆角轮廓外部透明。没有嵌入位图、阴影滤镜或随机纹理。

重新导出（设计工具，不是应用运行依赖）：

```powershell
python -m pip install Pillow
python scripts/export-icon.py
```

脚本调用已安装的 Edge/Chrome 渲染 SVG，再导出 16、20、24、32、40、48、64、96、128、256 像素的 ICO 图层，并校验内部透明度及图层尺寸。普通构建直接使用已提交的 PNG/ICO。
